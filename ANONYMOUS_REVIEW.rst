匿名评审入口说明
================

本项目只维护并发布一份源码：``repository/``，对应压缩包为 ``source.zip``。
正式入口与匿名入口提供同一固定源码版本；算法、环境、配置、模型与数据的对应
关系完全相同。统一源码包已处理已知直接身份信息，且不携带原 ``.git`` 历史。
匿名入口负责隐藏所有者、提交者、正式仓库地址等身份展示信息。
正式仓库目前私有，匿名入口和资料附件尚未发布；本说明不提供未取得的链接。

已核对学校现行撰写规范与匿名评阅要求，未找到关于匿名外链的专门说明，
不能据此预设外部匿名服务或在线附件已获允许。论文盲审模式默认不填写匿名外链。学校允许且匿名资料已通过无登录浏览、下载及内容核查
后，才配置实际匿名入口；正式模式配置正式仓库地址。匿名链接未配置时不回退
到实名地址。

一份源码与两个访问入口
------------------------

盲审期间，维护源可继续保持私有；匿名快照按实际要求作为评审附件或通过合适的
匿名入口提供。盲审结束后，再将同一源码与配套资料公开。两个入口不要求建立
两个 GitHub 仓库，也不要求生成两份具有不同版本标记的源码包。

若需要独立匿名托管，应从已检查的匿名快照发布，而不是把原仓库直接 fork 后
改名。匿名快照不携带原 ``.git``、提交历史、remote、作者身份或身份相关生成物。
改变 GitHub 用户名或当前提交邮箱不会自动移除旧提交中的身份信息。

已知直接标识检查
----------------

匿名导出需要检查第一方作者姓名、邮箱、单位、个人账号、实名仓库链接、本地绝对
路径，以及说明、日志、配置和输出中的身份字段。图像、PDF、Notebook 输出、
模型与其他二进制文件中的可见文字、内嵌路径和元数据也可能包含直接标识。

匿名状态只表示发布工具针对已知标识及所声明范围完成检查。它不保证所有二进制
格式已经去标识，也不保证无法通过代码、数据、方法名称或其他公开资料关联作者。
相关检查范围和剩余事项应以随发布版提供的核查结果为准，不使用“绝对匿名”的
描述。

第三方作者署名、许可证和来源说明必须保留，不能为了匿名删除第三方权利声明。
这些公开第三方信息与本文作者信息应分别判断。匿名处理也不能改动科学数字、
模型身份、DEV/TEST 区分和实验条件。

不宜在盲审期间同时公开内容相同的实名版本；两者可能被搜索或对照关联。
这是对直接身份泄漏以外关联风险的实际判断，不代表学校的具体评审规则。

使用 Anonymous GitHub 时的限制
------------------------------

Anonymous GitHub 是独立的第三方匿名镜像服务，不是 GitHub 本身的匿名模式。
按该服务当前官方 FAQ：

* 它匿名文本文件、文件和目录名称，并可使用自定义词项。
* 单个文件大于 8 MB 不受支持，完整模型与数据不能据此假定可托管。
* 二进制文件不做匿名转换；启用的图像、PDF 等可能原样提供。
* 可下载匿名 ZIP，但文本替换可能改变源码字符串或标识符，影响程序行为。

因此使用前需要检查实际可见文件、下载得到的内容、附件访问权限与必要运行入口。
不能把实名 GitHub Release、实名网盘或原仓库地址作为匿名包内的下载链接。
匿名服务的在线查看、文本替换或下载能力不等于可在线执行整个实验。

服务的项目文档包含通过 GitHub App 对所选私有仓库只读访问的能力。实际使用时
仍需核对所选部署的权限、私有来源访问和刷新结果，并从无登录访问者视角验证。
本项目尚未创建或验证该服务上的匿名镜像。
