当前活动对比方法
================

C-PPO、PFO、Gradient PPO、Reflective PPO和PPO+为本章五种外部对比。CrossQ仅保留历史模型兼容，spo模块仅为PFO的采集基础，不注册为第六种方法。

PFO已完成双环境五种子100608步从零训练及每模型128条独立终测。最后256条真实记录按64条小批量更新10轮，全部末段参与学习。方法公式与作者来源、许可及任务适配见pfo_provenance.json；当时的原始实现和工程记录继续保留。

当前维护源码用于后续开发，已完成结果使用各自实验目录的冻结源码和协议。原五种子批次与本次PFO批次按相同状态、学习步数及独立测试池组合，原两种子筛选不混入正式统计。
