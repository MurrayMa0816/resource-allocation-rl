图6.4双日期原生排版维护
==========================

当前正文使用pair_ab.pdf与pair_cd.pdf，每张原生画布156×225毫米。每日期地图110×92.52毫米，ID实际9.5bp，主要字实际10.5bp，两个日期共享110×21.5毫米图例。

默认维护命令
------------

python plot.py --output-dir 新目录

原维护代码全文保留，末尾只追加plot_pairs.py调用，在新目录同时复绘原四图及原图例、新两组图。也可单独执行python plot_pairs.py --output-dir 新目录。全部数据和辅助源位于本图目录及layout_pairs_20261110，字体使用论文工程assets/fonts本地文件。无历史HY外链依赖。

数据和几何
----------

原四日期89区数值、六角格/水渠/圆世界坐标保持。纸面投影从156毫米缩至110毫米，因此圆的纸面半径乘110/156、面积乘该比值的平方；共享图例使用同一比例。实际纸面毫米及平方毫米见pairs_layout_proof.json，旧CSV里的radius_mm保留其父图156毫米显示含义。

可读性调整
----------

四日期采用同一套标注位置，所有89编号字框间距至少1.2bp，并统一避开四日期最大配水圆的外缘。81个编号位置相对原156毫米地图有所调整，多数为小幅移动；最大纸面位移约5.8毫米，对较远位置增加灰色引线。既有标注线的首端随标签移动，区域归属末端锚点保持。新增引线锚点位于对应区域内部。label_adjustments.json记录全部变化及共同避让条件。

历史输出
--------

原四day与legend资产保留。历史PDF含原创建时刻，再绘时元数据会变化，应按独立复核的文字、几何与RGB判断原输出内容是否保持；新两组图使用固定元数据并验证PDF/SVG/PNG字节复绘。
