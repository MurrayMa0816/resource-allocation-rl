工程准备命令
------------

在 /root/gamewar 下，以选定隔离环境的 python 执行以下模块：

1. python -m chapter5_cross_server_20261103.validation --output <新工程验收目录>
2. python -m chapter5_cross_server_20261103.register --output <新任务根>
   --readiness <工程验收目录>/readiness.json --python <隔离环境python>
3. python -m chapter5_cross_server_20261103.launch --output <新任务根>

第 3 步默认只检查，不创建训练进程。尚未完成密集存储测量时，任务清单标记为
prepared_awaiting_target_preflight，调度器拒绝正式执行；不得伪造测量回执。
--measured-storage 可绑定同版代码的容量实测回执。只有完成目标机软件、
数据、源码、配方、容量、资源检查，且正式训练已获确认后，才使用 --execute。

调度器读取 cgroup v1/v2 的真实 CPU 与内存配额，保留至少一核与 8 GiB 内存。
同一方法/场景的 seed410 先验证真实 512 步健康数据，再允许其余种子扩展。
不终止其他进程，不自动重试失败训练，不以旧队列接管未完成工作。
工程短前缀一致性测试不构成完整训练结果或方法优劣证据。
