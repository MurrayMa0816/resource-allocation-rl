第四章全额分配环境接口
======================

来源与分配约束
--------------

release 使用第三章 full_spend_revision_20261104 的固定环境源码。图像数组由
Task.data_root 绑定只读数据路径，图像、划分和核心源文件的 SHA 随进程记录并
核验。不同环境映射或配置所得结果应分别标识。

总量映射沿用第三章：应急末期下界等于余额；通信按公开进度和剩余时段计算未来
保证可花容量及当前总量下界。保留对象上限、已完成终端零功率、非负约束、原生
物理过程和终点评价。末轮许可区间退化为余额；float64 的 caps.sum() 与
count*pmax 允许终点容差内的 ULP 差异，不通过改写余额为零消除误差。

接入与进程隔离
--------------

引导接口为 chapter4_full_spend_env.bootstrap.install。应在对应方法的原生
解释器中、导入 allocation23、环境或 runner 之前调用，例如::

    from chapter4_full_spend_env.bootstrap import install
    identity = install(audit_dir=OUT / 'resource_audit',
                       context={'method': method, 'seed': seed, 'variant': variant})

bound_worker_example.py --config PATH 给出新进程入口示例。解释器切换必须在
install 前完成；安装后再调用会重新执行解释器的旧 CLI 将丢失内存绑定。
各方法的具体解释器和环境依赖按其登记配置选择。

install 每个进程只能调用一次；若其他 allocation23、环境或 runner 已导入则
拒绝继续，不在运行中替换模块。chapter4_recent_baselines.env_adapter 与
allocation23.task.Task 使用同一接口。

资源账本与概率接口
------------------

FullSpendPhysicalGuard 只使用公开状态和实际动作，不增加学习输入或环境随机
调用。即使采样器绕过 Task.episode 直接调用 task.env.step，也执行相同检查。
每个完整回合的摘要见 task.env.last_full_spend_audit，并追加至
resource_audit/resource_episodes_PID.jsonl。记录包括 phase/index、逐时段总量
及上下界、余额、负量/对象超限/完成对象投入违规、逐步余额误差及回合资源总和。
日志不作为学习输入；Env 逐步返回空 info，非终点奖励为零。

通信 initial_budget/total_used/remaining 使用功率账本单位；
*_physical_resource 乘 action_cost_scale=.001 后才以 J 计。应急比例系数为 1，
物理单位为等效柴油 L。

完整 raw、联合 Gaussian log_prob、mask 和行为 mean/sigma 字段保持原形。
Actor.sample、Actor.log_prob 沿用原第四章实现，空间 decode 加入第三章的总量
可行性保护。F1 根据完整潜在联合事件计算行为概率和 V-trace，不对投影后的物理
动作另求密度。末轮总量区间退化时，mask 仍按预算可用性定义，联合概率仍包含
总量潜变量。继承的 quota_transform 元数据描述与实际映射的区别由运行 identity
说明，不改变概率维度或执行数学。

已有检查范围
------------

acceptance/attempt04/shared_bridge_acceptance.json 记录两域各 4 种 raw 模式及
逐动作回放，共 16 条完整路径、448 次真实工程交互和 21 项拒绝负例；没有训练
更新、holdout 或 CUDA 执行。记录中的最大相对分配误差为
8.881784197001252e-16，对象超限、负量和向完成对象投入的违规均为零。

附带的七方法接口检查隔离各进程并保留原网络宽度，只检查网络输出、概率接口和
真实环境完整轨迹，不执行优化器。TD-MPC2 的 CPU 记录仅覆盖 WorldModel 的
encode/pi/next，不证明 CUDA MPPI 规划闭环；PGR 记录覆盖 256×256 策略与原密度，
不证明扩散训练/生成闭环。接口检查不等同学习有效性验证，也不决定论文最终采用
的基线名单。
