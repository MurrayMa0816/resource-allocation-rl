第四章统一全额分配接口
====================

本目录只建立新的环境执行合同及审计接口。它不改第三章、旧第四章、第二章、
第五章的冻结源码、模型、进程或论文。原第四章的训练成绩不能与本轮结果直接混池。

执行来源
--------

``release`` 复制第三章 ``full_spend_revision_20261104/execution/source`` 的
176份文件，共9,049,066字节。331,776,128字节图像数组没有重复复制，而是由
Task的显式 ``data_root`` 绑定原只读数据路径，图像和划分文件SHA均进入运行身份。
复制目录的全部文件SHA与四个全额分配核心源SHA均在每个新进程准入时核验。

总量映射完整沿用第三章：应急末期下界等于余额；通信使用当前公开包进度与
剩余时段计算未来保证可花容量，并保留当前总量下界。对象上限、已完成终端
零功率、非负约束、原生物理过程和终点评价均保留。末轮许可区间在数学上
退化为余额；float64的 ``caps.sum()`` 与 ``count*pmax`` 允许同源终点容差内的
ULP差异，不改写余额为零。

最小接入
--------

在正确的原生解释器中，且尚未导入任何旧环境或学习器之前执行::

    sys.path.insert(0, str(SCOPE / 'source/env'))
    from chapter4_full_spend_env.bootstrap import install
    identity = install(audit_dir=OUT / 'resource_audit',
                       context={'method': method, 'seed': seed, 'variant': variant})
    from chapter4_recent_baselines.runners.reference_runner import run
    run(config)  # A/F1；其他方法直接导入各自runner并调用run(config)

``bound_worker_example.py --config PATH`` 提供完整的新进程入口示例，未自动启动。
A/F1、PROPS、ADDQ使用系统解释器；FoG使用旧prepared runtime/jax；
TD-MPC2/PGR使用旧prepared runtime/torch。不要先安装桥再调用旧
``python -m chapter4_recent_baselines``：旧CLI会重新执行解释器，丢失内存绑定。
示例入口如需切换解释器，会重新执行自身后才安装桥。

防混版本
--------

``install`` 每个进程只能调用一次。若旧 ``allocation23``、旧Env或任一旧runner
已导入，立即拒绝继续；不在运行中替换环境。所有原有runner看到的
``chapter4_recent_baselines.env_adapter`` 与原生 ``allocation23.task.Task``
均明确指向同一新接口。

全额账本
--------

透明 ``FullSpendPhysicalGuard`` 只用已有公开状态和实际提交动作校验，不增加
任何学习输入，也不调用新的环境随机数。A/F1原采样器即使绕过
``Task.episode`` 直接调用 ``task.env.step``，也由此同一层检查。

终点摘要可读 ``task.env.last_full_spend_audit``；每个完整回合自动追加至
``resource_audit/resource_episodes_PID.jsonl``。记录含phase/index、逐时段
总量及上下界、实际余额、负量/对象超限/完成对象投入违规、逐步余额误差、
全回合资源总和及绝对/相对误差。日志是审计输出，Env每一步仍返回空info，
非终点奖励仍严格为零。

通信 ``initial_budget/total_used/remaining`` 使用原功率账本单位；
``*_physical_resource`` 已乘 ``action_cost_scale=.001``，单位才是J。
应急比例系数为1，物理单位为等效柴油L，不能把功率账本直接标作J。

概率与F1兼容
------------

完整raw、联合Gaussian log_prob、mask以及旧行为mean/sigma字段保持原形。
``Actor.sample`` 与 ``Actor.log_prob`` AST与旧第四章完全一致；空间decode只新增
第三章的总量可行性保护。F1仍基于完整潜在联合事件计算行为概率和V-trace，
不对投影后的物理动作另求密度。

末轮总量受约束退化时，原第三章mask仍按预算可用性定义，联合概率仍包含
总量潜变量；本轮沿用已验收语义，不静默删除概率维度或改变mask。原Actor
metadata中继承的旧quota_transform字符串不是新执行数学，运行identity明确
给出全额映射及该描述勘误。

验收范围
--------

``acceptance/attempt04/shared_bridge_acceptance.json`` 是完整可复现的通过记录：
两域各4种raw模式及其逐物理动作回放，共16条完整路径、448次真实工程交互、
21项拒绝负例，零训练更新、零holdout、零CUDA。最大相对分配误差为
8.881784197001252e-16；对象超限、负量、向完成对象投入的违规均为零。
第1至3次测试失败记录均保留；失败来自门禁脚本对空间decode新增保护、
ULP末期区间的过强逐位断言，未改写第三章数学或原生动作。

七方法原生接口检查另按方法隔离进程，保留原网络宽度，仅验证网络输出、
概率接口和真实Env完整轨迹，不执行优化器更新。TD-MPC2的CPU检查覆盖官方
完整WorldModel的encode/pi/next，不能冒称已验收CUDA MPPI规划闭环；
PGR检查覆盖官方256×256策略及原密度，不能冒称已验收扩散训练/生成闭环。
学习有效性与通信不学习原因仍须由后续独立训练对照判断。
