第四章有效性评价：问题、指标与证据的对应关系
========================================

固定研究问题
------------

在同一多轮资源配置任务中，如何可靠利用已采集的近期完整轨迹，使策略用更少的新增真实环境交互达到指定配置质量。
F1保留第三章A的资源决策思想，改变数据组织、旧策略概率校正及学习更新。
只有回合终点奖励是固定任务条件；本次对比不把它预先认定为样本效率不足的独有原因，也不把研究问题改回信用分配。

1. 直接证明目标：达到同一目标所需的新增真实交互步数
--------------------------------------------------

设第k个固定开发评估点的新训练交互累计量为n_k，独立开发路径上的平均配置得分为J_k。
目标q在正式训练前固定。定义：

    N_q = min { n_k : J_(k-1) >= q 且 J_k >= q }。

也就是连续两次通过，使用第二次确认时的真实训练步数。warmup计入；回放读取、梯度更新、潜模型模拟不冒充新增真实交互。
未达到目标的种子标记右删失，不能删除后只平均成功种子，也不能把预算上限写成已经达到目标的N_q。
对全部成功且比较口径一致的配对，可报告节省比例1-N_q(F1)/N_q(control)。

这不是再次比较最终任务分数：固定配置质量后，比较的是训练所需交互成本。

2. 展示整个训练过程：训练种子达标比例
------------------------------------

    F(n) = 达到确认标准且N_q <= n的训练种子数 / 训练种子总数。

横轴是新增真实训练交互步数，纵轴是独立训练种子中已经达标的比例。
这不是用户接收成功率或应急任务完成率。同一预算下曲线更高，表示更多训练种子已经学到要求的策略；曲线更早上升，表示更早学到。
保留全部未达标种子，少量种子时如实显示阶梯，不伪装成连续概率估计。

metrics/第三章A与F1_训练种子达标比例.pdf复用既有V2种子60--64、480回合数据，零新增训练。
既有目标通信30、应急65，两环境原A均4/5个训练种子确认，F1均5/5。
这是已有五种子的描述，不是本轮五个新baseline结果，也不是普遍优越的统计结论。

3. 解释收益来自哪里：匹配消融，而非仅展示复用次数
------------------------------------------------

保留第三章A作为整体基线，另用已有F0：与F1保持相同新轨迹数、更新时刻、批次槽位和梯度次数，把旧轨迹替换为当前轨迹副本。
F0不是第三章A。F1-F0衡量这个匹配后端中真实旧数据及其必要概率校正的联合增量。

既有V2五种子全部达标时，通信F0→F1平均确认成本11673.6→9830.4步，节省15.79%；应急6220.8→5760.0步，节省7.41%。
这些比例不能改写成相对原A的节省，也不能冒称新五baseline实验结论。
既有预注册显著性检验的主指标仍是开发AUC，不把其p值挪给N_q；本轮新baseline正式研究应在读取其结果前另锁分析方案。

F1内部另外记录：旧轨迹密度比、ESS/n=(sum w)^2/(n sum w^2)、权重截断比例、更新前后实际联合策略KL、非有限值/概率重算误差。
它们解释旧数据是否严重偏移、权重是否集中、更新是否失控；不能单独证明配置质量或样本效率提高。
原A没有历史轨迹，不能把“原A无ESS、F1有ESS”画成更优。

此前梯度诊断的误差降低仅是有限参考、固定旧历史条件下的辅助证据，方向一致性并非全部稳定改善。
本次不通过增加loss、ESS或梯度图来替代直接目标与消融证据。

4. 排除代价转移：计算开销与独立测试表现
--------------------------------------

分列：训练真实交互、开发/测试真实交互、actor/critic/model梯度更新、模型或生成样本数量、GPU/CPU设备、采样/学习/评估用时和总墙钟。
样本更省不等于计算更省；FoG的高UTD与扩容、PGR生成训练、TD-MPC2规划的额外计算必须保留。
同一预算下的开发曲线归一化AUC是辅助学习过程指标；最终独立路径上的得分及其配对置信区间用于检查所达质量。
不以训练loss更小、更新次数更多、复用次数更多或单个种子更好代替有效性。

新五baseline的比较约定
-----------------------

同一原生radio/v5环境、终点0/R奖励、真实有限终止、公开信息与固定A_FULL可行解码器；不提供未来状态、仿真oracle或额外过程奖励。
神经观测305/244维，分别覆盖A原有local/global和quota head使用的两项公开预算输入；不是额外特权信息。
PROPS使用原始Gaussian潜动作；其余方法使用tanh坐标并由共同atanh适配回原始潜动作。
所有概率在各自潜动作坐标计算，不在投影后的物理资源向量上伪算高斯概率。

正式开发协议：第0点，随后每48回合，固定32条开发路径；主要使用原生随机执行，训练RNG与评估RNG隔离。
TD-MPC2的官方eval_mode仍有规划候选随机性，不能称其为确定性均值策略。
不同方法保留原生网络和学习机制，这是完整算法对比；单一组件的因果解释依靠匹配消融。

本轮仅完成代码和小规模机制/接口验收，没有启动新五baseline正式性能实验。
