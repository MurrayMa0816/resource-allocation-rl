第四章双随机初始化批次的验收与自动发布
======================================

调用与门禁
----------

execution/postprocess.py 仅在190项结果齐全后调用独立验收，再聚合并发布。90项训练记录由50项本轮从零训练与40项沿用的外部方法训练组成，另有100项共同终点评价。60项终测新执行，40项沿用同一测试面板的原外部评价。10个新版第三章A只复用固定终点，不把原512步乘8情景的开发曲线混入本章768步乘32情景的学习曲线。

python3 execution/publish_thesis.py --scope 本scope --publish

默认或 --prepare 只在190项独立验收与聚合CSV绑定通过后生成HY暂存稿。--self-test 以及 preflight/publisher_tests 下的两个测试脚本均只使用独立工程输入，不触发真实论文编译，不构成科学结果。代码胶囊应在全部工程门禁与源审查完成后，用 execution/seal_postprocess.py --seal 建立，训练完成不等于代码或结果自动验收通过。

初始化与统计
------------

TRoC和三项消融以及PROPS改为双随机输出头。TRoC与消融在相同种子下保持同一初始模型，PROPS复制同来源的随机策略均值模板，保留其float32与可学习标准差。PGR和ReDo及MR.Q和BRO不使用该模板，它们的原生初始化与学习规则保持原来源。

主要质量门槛沿用原预登记绝对数值，不因新初始化的结果改变。内部q90/q95/q100数据键仅承接原门槛文件，不表示新版第三章A的90/95/100百分比。正文显示较低目标、主要目标和较高目标，并交代原门槛来源。连续两次原始DEV确认步数、预算内确认数、受限交互成本与AUC按五次独立训练统计。未达标保留右删失，不能强行平滑、单调化或以最佳周期模型替换固定终点。

原外部40次训练的新交互数4024320为原先已经发生的成本，本轮新50次训练的新交互数5030400单独报告。新/复用开发和终测成本也按来源分开。复用模型及其曲线不称为本轮新训练，C3模型原训练不在本轮再次计为实际学习。

图表与写作
----------

三节职责依次是实验设置、样本效率与消融、预算窗口与更新内部指标。六组图保留本地CSV、plot.py、figure_config.json及source.json。ESS和KL只描述权重与分布差异，组件收益由消融中的同等质量交互需求和配置成效决定。原始日志及不重叠内部汇总保持可核查。

只更新当前第四章4.3、小结、六组实验图和图索引，另同步必要的全额分配合同陈述。现行方法的其余数学和三幅drawio保留。准备阶段读取最新论文并以逐SHA比较防止覆盖并行修改。按现行写作细则保持三个三级标题，中文叙述不用顿号、冒号和分号等受限标点，结果文字由真实数值和正负方向生成。

集成前保存旧第四章、图索引和PDF。调用唯一整稿入口 scripts/build.sh，五轮均强制真实XeLaTeX并分别检查结构、原始数据绑定、字体与实际渲染和PDF数值。其他章节的并行改动保持，不以旧整稿覆盖新稿。

最终不可变PDF为 publication/final/main.pdf。FINAL_THESIS_PUBLICATION.json 仅在真实验收、聚合、五轮编译和自动PDF检查全部通过后写入published=true。manual_visual_review保持pending，实际渲染不冒称人工检查。全部工程、绘图和编译缓存实体位于HY。
